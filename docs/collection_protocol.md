# 数据收集协议 Collection Protocol — Track 5 试点数据

## 1. 研究问题与目标

> BA（商业分析）/ DS（数据科学）硕士项目的招生面试考察什么？不同地区与项目类型有何差异？WKU 申请者应如何准备？

试点目标（9 月）：建立 **≥100 条可验证记录** 的 pilot dataset，跑通「抽样→收集→编码→清洗→分析」全流程，为 10–12 月的正式扩展（≥300 条 + 访谈）提供方法论验证。

## 2. 抽样框（Sampling frame）

| 维度 | 设定 |
|---|---|
| 总体 | 美 / 英 / 中国香港 / 中国澳门 / 新加坡 / 澳大利亚高校开设的 BA、DS（含 Analytics 方向）授课型硕士项目 |
| 抽样单元 | 单个硕士项目（院校+项目名唯一） |
| 搜索词 | 英文：`MS Business Analytics admission interview`、`MSc Data Science interview`、`Kira interview graduate admission`、`[校名] admissions interview`；中文：`商业分析 硕士 面试`、`数据科学 硕士 面经`、`[校名] 面经` |
| 时间窗口 | 官网页面以 2026 Fall 入学信息为准；面经帖采集 2023–2025 年内容 |
| 纳入标准 | ① 属 BA/DS/Analytics 范畴；② 属于上述 6 地区；③ 官网或可验证面经中存在面试相关明确信息 |
| 排除标准 | ① 无任何可检索的面试信息；② 无来源、无法复验的匿名帖子；③ 与数据分析无关的项目（如纯会计/金融方向，除非项目名称明确含 Analytics） |
| 理由 | 服务 WKU 申请者决策：上述 6 地区是 WKU 学生主要申请目的地；仅纳入可验证信息以支撑「基于证据的准备方案」而非道听途说 |

## 3. 数据收集策略（按优先级的回退阶梯）

**第一优先级（首选）**
1. **院校招生官网**（Admissions / FAQ / Interview 页面）——获取面试形式、平台、是否邀请制等事实。
2. **Reddit r/gradadmissions 官方 API**——计划通过官方 API 抓取面试经验帖。
   - 实际执行结果：Reddit API 因网络环境无法稳定访问（被墙/限流），**触发回退**，未使用 Reddit 数据。

**第二优先级（主路径，本次试点实际执行）**
3. **中文面经社区手动收集**：小红书、知乎、一亩三分地、新东方留学、指南者留学等平台的面经帖。
   - 小红书与一亩三分地有登录墙，采用**手动浏览 + 结构化摘录**（不批量爬取，遵守平台条款）。
   - 每个面经信息点均以「院校官网」作交叉验证（试点 100% 覆盖），无法验证的不入库。


## 4. 收集步骤（每条记录）

1. 确定目标院校/项目（从 QS/THE 排名 + WKU 往届录取清单圈定）。
2. 打开官网 Admissions 页，记录：项目名、面试形式、平台、时长、是否邀请制 → 写入来源 URL。
3. 在面经社区用搜索词检索该项目的面经帖，摘录：问题类型、典型题目、流程细节。
4. 核对两源信息一致性；不一致时以官网为准并备注。
5. 按 `docs/coding_scheme.md` 编码，录入 Excel（本次为 `BA_DS硕士面试数据收集表_100条.xlsx`）。

## 5. 数据规模与构成（试点）

| 地区 | 记录数 | 主要面试形式 |
|---|---|---|
| 美国 | 40 | 部分候选人评估制 45%、异步录播 25% |
| 英国 | 18 | 部分候选人评估制 78%（多为 MSc Business Analytics 方向） |
| 中国香港 | 18 | 真人视频 67% + 笔试组合 11% |
| 新加坡 | 13 | 笔试/机考+真人面 39% |
| 澳大利亚 | 9 | 部分候选人评估制 100% |
| 中国澳门 | 2 | 真人视频 100% |

## 7. 伦理与合规

- 仅使用公开信息（官网、公开面经帖），不爬取登录墙内容、不绕过任何反爬机制。
- 不记录面经中的个人身份信息、offer 结果、成绩等敏感数据。
- 访谈轮（12 月）将先取得受访者知情同意，匿名化处理。
