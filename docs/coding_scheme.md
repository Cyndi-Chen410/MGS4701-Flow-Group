# 编码表 Coding Scheme — Track 5 试点数据

> 用于 `data/pilot_dataset_raw.csv` → `data/pilot_dataset_cleaned.csv` 的标准化工序。
> 全部转换逻辑可复现于 `notebooks/01_data_cleaning.ipynb` 与 `scripts/01_clean_data.py`。

## 1. 变量字典（原始 11 列）

| 字段 | 说明 | 缺失规则 |
|---|---|---|
| 序号 | 1–100 唯一编号 | 无缺失 |
| 国家/地区 | 项目所在地区：美国 / 英国 / 中国香港 / 中国澳门 / 新加坡 / 澳大利亚 | 无缺失 |
| 院校 | 开设院校（中文名+英文名） | 无缺失 |
| 项目名称 | 硕士项目官方名称 | 无缺失 |
| 面试形式 | 原始自由文本（49 种写法） | 无缺失 |
| 面试平台 | 视频平台/面试系统，如 Kira Talent、Zoom | 无强制面试的项目允许缺失 |
| 题目数量/时长 | 原文描述（题目数、作答时长、总时长） | 无缺失 |
| 问题类型 | 从面经/官网归纳的问题类别描述 | 无缺失 |
| 典型面试问题示例 | 1–3 道可验证的示例问题 | 无缺失 |
| 数据来源（可搜索验证） | 官方页面 URL 或面经帖子位置 | 无缺失 |
| 来源类型 | 来源组合标签（院校官网 + 知乎 / 小红书 / 一亩三分地…） | 无缺失 |

## 2. 派生变量（清洗新增 5 列）

### 2.1 面试形式编码（8 类）

| 编码 | 中文 | 定义 | 原文示例 |
|---|---|---|---|
| `selective` | 部分候选人需面试（评估制） | 项目以材料审核为主，仅部分申请者获邀面试；无强制全员面试 | 「部分候选人面试（评估制）」「部分项目需面试」「行为面试（邀请制）」 |
| `async_video` | 异步视频面试（录播） | 申请者按系统提示限时录制回答（通常 Kira Talent / WePow / 自建平台），无真人互动 | 「异步视频面试（录播）」「视频面试（录播）」「案例分析视频面试」 |
| `live_video` | 真人视频面试 | 与招生官/教授实时视频或线下面试 | 「视频面试（Zoom）」「真人线上单面」「结构化面试」 |
| `phone` | 电话面试 | 纯电话形式 | 「电话/Skype面试」 |
| `written_live` | 笔试/机考 + 真人面试 | 先有笔试或机考环节，另有真人面谈 | 「笔试+面试」「线上机考 + 真人面谈」「两轮面试：机面+真人面」 |
| `group` | 群面/小组讨论 | 以小组讨论为主要形式 | 「小群面」「小组讨论(TBD) + 一对一面试」 |
| `mixed` | 混合形式 | 单面/群面/录播组合，未细分 | 「Video / 真人单面 / 群面」 |
| `none` | 无强制面试 | 明确无需面试，靠文书/标化/GRE 评估 | 「无强制面试（需提交GRE/GMAT）」 |

### 2.2 平台标签

从「面试平台」文本抽取，一行可多标签（逗号分隔）：`Zoom` / `Kira Talent` / `WePow` / `自建平台` / `Skype` / `Lantern AI` / `Astronaut` / `在线机考平台` / `线下·校园` / `电话`。

### 2.3 题目数量(解析) / 时长分钟(解析)

- **题目数量**：`约N题`→N；`N-M题`→取中值 (N+M)/2（如 8-9 题→8.5）；`Q1-Q6`→6；`3题×1.5分钟`→3。仅原文显式报告题数才解析（100 条中 17 条），其余为 `NaN`。
- **时长分钟**：`N-M分钟`→中值；`N分钟`→N；累加多个片段。**排除**不包含「面试/真人面/面谈」字样的笔试、机考、技能评估、按小时计段（如「笔试2小时+面试10-15分钟」→仅 12.5 分钟）。
- **已知局限**：单题时长未乘以题数（如「3题；每题3分钟作答」→ 记 3 分钟而非 9 分钟）；「约8-9题」取中值而非区间。局限不影响本阶段结论方向，正式版（≥300 条）将改为区间字段。

## 3. 质量控制规则

1. 每条记录必须可溯源：含「院校官网」交叉验证（100% 满足），或来源 URL 可打开复验。
2. 同一院校 + 项目不允许重复记录。
3. 关键字段（国家/地区、院校、项目名称、面试形式、问题类型）不允许缺失。
4. 面经类信息仅记录在「面试形式 / 问题类型 / 示例问题」等描述字段，不采信面经中的成绩、offer 等个人数据。
5. 编码归并必须可复现：任何新增的「面试形式」原文写法须先加入 `FORMAT_MAP` 再重跑清洗。
